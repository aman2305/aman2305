# Security Policy

## Reporting Security Vulnerabilities
If you discover a security vulnerability within this project, please send an email to security@aman2305.example.com. All reports will be reviewed and investigated, and you will be contacted regarding your report.

## Supported Versions
This project is maintained and security updates are provided for the following versions:
- Version 2.0 and later

## Contact Information
For any security-related inquiries, please reach out at: security@aman2305.example.com
